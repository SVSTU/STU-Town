Biển chữ vector riêng, UTF-8 NFC, font Noto Sans Bold/Arial có đầy đủ dấu tiếng Việt. Năm file chữ riêng tương ứng labels.vi.json; schedule-sign.svg ghép đúng ba dòng giờ học thành một biển. Giữ vùng đệm và tương phản, kiểm tra font rồi chuyển outline hoặc xuất texture ở độ phân giải đủ đọc theo camera game. Không lấy chữ raster AI làm nguồn chữ cuối. Các file này chưa được gắn vào asset/map đang chạy.
